# Security Policy

This repository is a public demonstration surface using **synthetic workforce disclosure, acknowledgment, and escalation data only**.

## Data and secrets

- No live employee records, payroll data, tenant exports, or production credentials should be committed here.
- The repo demonstrates workforce disclosure-routing and review-posture patterns, not a production HRIS control plane.
- If you adapt this pattern for a real tenant, enforce least-privilege access, signed evidence packets, and reviewable audit logs.

## Reporting

Open a private security report through GitHub Security Advisories or email the maintainer if a vulnerability could affect downstream use of the patterns in this repo.
